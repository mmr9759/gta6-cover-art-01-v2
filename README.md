Vice State Cover Studio — turn any photo and a caption into GTA-style poster cover art, offline in your browser. Nine multi-panel layouts (Hero, Hero + Four, Grid Four, Full Bleed, Duo Split, Trio Strip, Strip Four, Magazine, Nine Grid), six skin-safe Vice City sunset / neon colour grades, poster-formula bold lettering, a photo library, drag-to-pan and zoom crops, a per-panel menu, undo/redo, a Surprise me button, and one-click PNG export in all three common post sizes (1080×1080, 1080×1350, 1920×1080). Photos never leave the machine. All art, lettering and grades are original — no Rockstar logo, artwork or fonts.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Add your photos, pick a layout and grade, edit the caption, and hit Export PNG (or Export all sizes).
